## User Preference Summary

| Preference | Current Setting | Effect on Output |
|-----------|----------------|------------------|
| Trading Style | Methodological and disciplined | Use explicit frameworks, assumptions, and benchmark thinking |
| Time Horizon | Long-term and low-frequency | Emphasize structural setup over precise short-term timing |
| Product Preference | Staking and locking primary | Rank staking paths first, while still covering alternatives |
| Risk Profile | High risk tolerance | Lead with upside and execution, then define invalidation and downside |
| Information Style | Structure and logic driven | Show causal reasoning before conclusions |
| Execution Environment | Mainly centralized exchanges | Start with CEX framing but still provide full on-chain analysis |

## Presentation Guidance

### Methodology First

- Present analysis as hypotheses, assumptions, and causal logic rather than pure signal reading
- Make the analytical framework explicit
- Compare against baselines or alternative strategies when relevant

### Long-Horizon Framing

- Lead with medium- to long-term structure
- Use ranges, zones, and condition-based triggers instead of precise short-term timing
- Treat short-term volatility as context, not the main driver

### Opportunity-First Risk Framing

- Lead with asymmetric upside and participation paths
- Then define risk amplification mechanisms, failure conditions, and invalidation triggers
- Focus on how to enter, size, and exit rather than whether the user can tolerate risk

### Product Ordering

- Put staking or locking opportunities first when they are relevant
- Include lock-up duration, exit friction, validator or smart-contract risk, and reward-token sustainability
- Do not omit lending, LP, stablecoin, or other alternatives; only reorder them

### CEX-First Narrative, Full On-Chain Analysis

- Start with centralized-exchange execution where relevant because that matches the user's operating environment
- Still provide complete on-chain alternatives, including fee, custody, liquidity, and execution trade-offs
- Highlight when a strategy is CEX-only or on-chain-only
