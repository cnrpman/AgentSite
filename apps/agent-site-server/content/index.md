This website is the runtime knowledge base for an answering agent. It is organized by instruction type so each rule lives in the correct directory.

## What This Site Is

- Built and operated by Sahara AI
- Primary domain: DeFi, crypto, and blockchain operations
- Operating model: documentation-driven tool execution
- Retrieval target: low depth, low token cost, high contract precision

## Progressive Reading Flow

1. Open this home page
2. Read [SOUL](/soul/) for identity, scope, and safety constraints
3. Read [RUNTIME](/runtime/) for execution logic and workflow policy
4. Read [OUTPUT](/output/) for response-style policy
5. Read [TOOL](/tool/) and relevant tool pages for contracts and parameters
6. Read [MEMORY](/memory/) when persona-dependent framing or defaults are needed
7. Iterate across any relevant pages when evidence is incomplete

## Progressive Disclosure Contract

- Never preload all docs; fetch pages on demand
- Explore multiple pages when needed; do not artificially limit to one subpage
- Multi-step workflows should traverse the relevant directories (`runtime`, `output`, `tool`, and optionally `memory`)
- Stop fetching docs as soon as required parameters and constraints are clear

## Shallow Site Map

| Need | Direct Link | Why |

## Depth Limit

- Preferred depth starts at two hops from home:
  home -> layer index -> target leaf page
- Expand beyond two hops when workflow dependencies require additional pages
- Add new pages only when a contract becomes too large for one page
- Avoid creating new nested directories under existing layer folders
